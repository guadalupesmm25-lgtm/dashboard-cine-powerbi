# Dashboard Interactivo de Ventas y Rendimiento (Power BI)

## 📝 Descripción
Proyecto de análisis y visualización de datos desarrollado en **Power BI Desktop**, basado en un conjunto de datos ficticio de ventas de boletos de cine. El informe analiza el rendimiento comercial, la distribución geográfica de las sucursales y el comportamiento de las ventas a lo largo del año.

## 🎯 Objetivo Principal
Proporcionar una herramienta analítica visual e interactiva para evaluar la rentabilidad por película, la eficacia de las sucursales y la interacción de los clientes mediante membresías, facilitando la toma de decisiones basada en datos.

## 📊 Estructura y Características del Dashboard
El reporte está dividido en 3 páginas interactivas estructuradas de la siguiente manera:

- **Estructura de Datos:** Modelado dimensional que relaciona 3 tablas principales (**Películas**, **Ventas** y **Membresías**).
- **Visualizaciones Dinámicas:** Cada página incluye al menos 3 gráficos interactivos, entre los que destacan:
  - **Gráficos de barras:** Comparativa de ingresos y boletos vendidos por título cinematográfico.
  - **Mapas geográficos:** Ubicación espacial de sucursales y densidad de ventas por zona.
  - **Segmentadores de datos (Filtros):** Selección interactiva por película, sucursal o periodo temporal.
- **Indicadores Clave de Desempeño (KPIs):**
  - Total de boletos vendidos.
  - Comparativa de tendencias mensuales.
  - Ranking dinámico de las películas más vistas (*Top Performing Movies*).

## 🛠️ Competencias y Habilidades Demostradas
- **ETL y Limpieza de Datos (Power Query):** Transformación, saneamiento y estructuración de fuentes de datos heterogéneas.
- **Modelado de Datos y DAX:** Creación de relaciones entre tablas e implementación de medidas DAX básicas para cálculos de métricas clave.
- **Análisis Geográfico y Visualización:** Diseño intuitivo de dashboards interactivos optimizados para la navegación del usuario.
- **Análisis Descriptivo:** Extracción de insights comerciales y evaluación de patrones de consumo.
