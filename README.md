# Panel Interactivo de Ventas y Rendimiento (Power BI)

## Descripción
Proyecto de análisis y visualización de datos desarrollado en Power BI Desktop a partir de un conjunto de datos de ventas de boletos de cine. El informe evalúa el rendimiento comercial, la distribución geográfica de las sucursales y la evolución de los ingresos a lo largo del tiempo.

## Objetivo
Crear un entorno analítico visual e interactivo para evaluar la rentabilidad por película, la eficacia de las sucursales y el nivel de interacción de los clientes según su tipo de membresía, facilitando la toma de decisiones basada en datos.

## Estructura del informe
- **Modelado de datos:** Modelo dimensional que vincula las tablas principales de Películas, Ventas y Membresías.
- **Visualizaciones e interactividad:** Integración de gráficos de barras para comparar ingresos por título, mapas para analizar la densidad de ventas por zona geográfica y segmentadores para filtrar información por periodo, sucursal o película.
- **Indicadores clave (KPIs):** Métricas de boletos vendidos, comparativas mensuales de rendimiento y ranking dinámico de películas con mayor recaudación.

## Habilidades y conceptos aplicados
- **ETL y limpieza de datos (Power Query):** Transformación, saneamiento y estructuración de tablas.
- **Modelado de datos y DAX:** Definición de relaciones relacionales e implementación de medidas DAX para el cálculo de métricas de negocio.
- **Visualización y diseño de dashboards:** Creación de vistas interactivas orientadas a la exploración intuitiva de datos.
- **Análisis descriptivo:** Identificación de patrones de consumo e extracción de insights comerciales.de consumo.
